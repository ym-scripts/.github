# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub's [private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) ("Report a vulnerability" on the repo's **Security** tab), or email **youngmayor.dev@gmail.com** with `[ym-scripts security]` in the subject.

Include the affected tool and version, steps to reproduce, and the impact. You'll get a reply within 5 working days.

## Supported versions

Only the latest release of each tool gets security fixes. Pin a tag (`npx github:ym-scripts/<tool>#vX.Y.Z`) and upgrade when a fix is released.
